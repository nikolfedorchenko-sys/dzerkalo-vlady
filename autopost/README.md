# Автопостинг «Дзеркало влади» – як це працює

Сім разів на день – о **08, 10, 12, 14, 17, 19 і 21** за Києвом – у хмарі GitHub сам запускається робот:

1. **Пошук.** Читає 17 джерел: Верховна Рада, КМДА, Кличко, Офіс Президента, Зеленський, НБУ (офіційні) і Слово і Діло, Київ Влада, Суспільне, УП, ЕП, Інтерфакс, Укрінформ, LB.ua, ДТ (медіа). Бере тільки нові матеріали за 12 годин.
2. **Фільтр.** Матеріали зі словами на кшталт «футбол», «гороскоп», «прогноз погоди» відкидаються одразу, без Claude (список `skip_words` у `config.yaml`).
3. **Відбір (Claude Sonnet).** Вибирає сюжети про владу, об'єднує повтори з різних джерел і ставить оцінку важливості від 1 до 10. Публікуються сюжети від 5 балів.
4. **Написання (Claude Opus).** Читає повні тексти джерел і пише три різні тексти: розгорнуту статтю для сайту, короткий пост для Telegram і колонку з думкою для Facebook.
5. **Редакторська перевірка (Claude Sonnet).** Звіряє чернетку з джерелами: вигадані факти, думка під виглядом факту, образи, довге тире. Якщо хоч щось не так, матеріал не виходить.
6. **Публікація.** Новина додається на сайт, за 1–2 хвилини Cloudflare оновлює сайт, потім виходять пост у Telegram і Facebook з карткою-картинкою.
7. **Звіт.** Вам в особисті приходить повідомлення від бота: що опубліковано і що відхилено (і чому).

## Що де виходить

| Де | Який текст | Правила |
| --- | --- | --- |
| Сайт | Повна стаття: факти, цитата, «Контекст», «Що це означає для тебе», «Що далі», «Думка редакції» | `правила/сайт.md` |
| Telegram | Коротко, до 350 знаків: факт + одне гостре речення | `правила/telegram.md` |
| Facebook | Колонка 900–1500 знаків: чіпкий початок, факт, аналіз, думка ДВ, питання до читачів | `правила/facebook.md` |

## Як змінити тон, довжину чи правила

Усі інструкції для Claude – звичайні текстові файли в папці `autopost/правила/`. Правите текст, зберігаєте на GitHub – з наступного запуску робот пише по-новому.

| Файл | Що в ньому |
| --- | --- |
| `голос.md` | Хто ми, тон ДВ, залізні правила (без вигаданих фактів, без образ) |
| `відбір.md` | Які новини беремо, які ні, як ставити оцінку важливості |
| `сайт.md` | Будова статті на сайті |
| `telegram.md` | Пост для Telegram |
| `facebook.md` | Пост для Facebook |
| `перевірка.md` | За що випусковий редактор відхиляє матеріал |

«Терміново» на сайті знімається саме через 6 годин (`urgent_hours`).

## Claude: підписка Max

Робот працює через Claude Code на вашій підписці **Max 5x** – окремо за API не платимо.
Щоб економити ліміт: відбір і перевірку робить Sonnet, тексти – Opus; очевидно зайве відсіюється словами-фільтрами; робот працює лише 7 разів на день.
Ліміти підписки спільні з вашою роботою в Claude. Якщо ліміт вичерпано, робот нічого не ламає: пропускає запуск і розбирає ці новини наступного разу.
Якщо лімітів почне бракувати: зменшити `max_posts_per_day` або години в `slots`; у змінній `DV_MODEL` поставити `claude-sonnet-5-5` (тоді й тексти пише Sonnet).

## Режими

Режим задається змінною `DV_MODE` у GitHub:

| Режим | Що відбувається |
| --- | --- |
| `live` (зараз) | Усе по-справжньому: сайт, @dzerkalo_vlady, Facebook. |
| `test` | Пости йдуть тільки в пробний Telegram-канал (`TG_TEST_CHANNEL_ID`). Сайт і Facebook не чіпаються. |
| `dry` | Тільки на комп'ютері: нічого не публікує, кладе чернетки й картки в `autopost/out/`. |

## Секрети та змінні в GitHub

Сторінка: https://github.com/nikolfedorchenko-sys/dzerkalo-vlady/settings/secrets/actions

**Secrets** (приховані):
- `CLAUDE_CODE_OAUTH_TOKEN` – токен підписки Max (команда `claude setup-token`, діє рік, до ~жовтня 2027);
- `TG_BOT_TOKEN` – токен бота @dzerkalo_vlady_autopost_bot;
- `FB_PAGE_TOKEN` – постійний токен сторінки Facebook;
- `ANTHROPIC_API_KEY` – не потрібен; тільки якщо колись перейдемо на платний API.

**Variables** (звичайні):
- `DV_MODE` – `live`;
- `TG_CHANNEL_ID` – `@dzerkalo_vlady`;
- `TG_ADMIN_CHAT_ID` – ваш chat id (звіти);
- `FB_PAGE_ID` – 1415145338342034;
- `DV_MODEL`, `DV_MODEL_FAST` – необов'язково: інші моделі для текстів і для відбору/перевірки.

## Як запустити вручну

https://github.com/nikolfedorchenko-sys/dzerkalo-vlady/actions/workflows/autopost.yml → **Run workflow**.
Вручну робот працює в будь-яку годину. У полі «Що зробити» є ще «Перевірити Facebook» – публікує на сторінці останню новину з сайту (знадобиться після оновлення токена Facebook).
Журнал кожного запуску – там само; картки за останні 7 днів лежать у запуску в розділі Artifacts → cards.

## Джерела

`autopost/config.yaml`, розділ `sources` – по одному рядку на джерело, приклади нагорі файлу.
Офіційних каналів Кабміну й Київради з робочою стрічкою не знайшлося (сайти kmu.gov.ua, kmr.gov.ua, kyivcity.gov.ua, president.gov.ua блокують роботів). Їхні рішення приходять через медіа.

## Файли

- `run.py` – головний сценарій; `collect.py` – збір; `brain.py` – запити до Claude; `card.py` – картки; `publish.py` – сайт, Telegram, Facebook.
- `правила/` – інструкції для Claude (див. вище).
- `.github/workflows/autopost.yml` (у корені репозиторію) – розклад.
- `.env` – секрети для запуску на комп'ютері (не потрапляє в git), зразок – `.env.example`.
