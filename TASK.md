# Завдання: сайт «Дзеркало влади»

## Що вже є
- `design/index.html` – **затверджений макет головної** (стиль «преміум v2»). Відкрий у браузері – це еталон вигляду.
- `design/site-v2.css` – кольори, шрифти, заокруглення стилю v2. Беремо тільки їх.
- `design/article-v1.html`, `design/about-v1.html` – макети статті й «Про нас» у **старому** стилі v1. Структуру й блоки беремо звідти, а вигляд переводимо у v2.
- `design/home-v1.html` – стара головна, тільки для довідки.
- `design/assets/photos/` – фото для макета + `CREDITS.md` з авторами.
- `brand/` – логотипи, шрифти, брендбук. Логотипи брати тільки звідти.

## Що зробити
1. Статичний сайт без фреймворків: HTML + один CSS + трохи JS. Викладка на Cloudflare Pages з приватного репозиторію GitHub (акаунт nikolfedorchenko-sys).
2. Сторінки:
   - `index.html` – головна, як у `design/index.html`;
   - `article.html` – шаблон статті: блоки з `article-v1.html` (лід, фото з підписом, «Що це означає для тебе», цитата, «Думка редакції», «Джерела», «Знайшли помилку?», «Читайте також»), стиль v2;
   - `about.html` – «Про нас»: місія, 4 принципи, «Хто нас фінансує», редакція, контакти, стиль v2;
   - `rubric.html` – сторінка рубрики (список карток новин з фільтром за рубрикою).
3. Новини – окремим файлом даних `data/news.json` (заголовок, лід, рубрика, дата, фото, підпис фото, джерела, текст), щоб редакція додавала новини без правки HTML. Головна, стрічка, рубрики й стаття будуються з цього файлу.
4. Спільні шапка й підвал для всіх сторінок, рядок «Терміново» показується лише якщо в даних є термінова новина.
5. Мобільна версія обов'язкова: меню ховається в кнопку, картки в один стовпчик.
6. Фавікон – `brand/logos/dv-favicon.svg`, картинка для соцмереж (Open Graph) – `brand/logos/dv-avatar-640.png`.
7. Після кожного етапу – показати результат локально і пояснити простими словами, що зроблено.

## Правила
- Мова – українська. Тире – тільки коротке (–).
- Кольори й шрифти – тільки зі `site-v2.css`. Червоний – тільки «Терміново».
- Під кожним фото – підпис з автором і ліцензією.
- Не вигадувати новини: у `news.json` – лише те, що є в макеті, або заглушки в [квадратних дужках].
