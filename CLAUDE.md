# Дзеркало влади (ДВ)

Незалежне медіа про владу в Україні: від Київради до Верховної Ради.
Слоган: «Влада – без фільтрів. Дивись, що вирішують за тебе.»

## З чого почати
1. Прочитай `TASK.md` – що будуємо зараз (сайт).
2. Відкрий `design/index.html` – затверджений макет головної, стиль «преміум v2». Це еталон вигляду сайту.
3. Брендбук – `brand/BRAND.md` (логотип, голос, рубрики, Telegram) і `brand/SOCIAL.md` (картки для соцмереж).

## Напрями роботи (кожен – в окремому чаті)
- Сайт – папка `site/`, інструкція `САЙТ.md`. Живий сайт: https://dzerkalo-vlady.com/ (запасна адреса – https://dzerkalo-vlady.pages.dev/)
- Автопостинг у соцмережі – папка `autopost/`, завдання `autopost/TASK.md`.

## Стиль сайту – «преміум v2» (важливо)
Для САЙТУ діють кольори, шрифти й форми з `design/site-v2.css`, а не палітра з `brand/tokens.css`:
- білий фон, світло-сірі секції `--bg-soft`, м'ятні блоки `--mint-soft`;
- фірмовий зелений `--green` для кнопок, рубрик і блоку Telegram;
- заголовки Literata 600–700, увесь інший текст Manrope;
- картки з заокругленням 12 px і тонкою рамкою, великі блоки 16 px;
- кнопки з м'ятним квадратиком і стрілкою (як на kmb.ua / kubatura.com.ua);
- жодних чорних блоків, важких ліній і тіней (тінь – тільки у плаваючої шапки);
- червоний `--urgent` – тільки плашка «Терміново».
`brand/tokens.css` – стара палітра брендбука для карток соцмереж; брендбук буде оновлено під v2.

## Логотипи
Тільки готові файли з `brand/logos/`, текст у них уже в контурах – не перемальовуй і не набирай назву шрифтом.
- `dv-wordmark.svg` – шапка сайту; `dv-logo.svg` – великий логотип («Про нас»);
- `dv-favicon.svg` – фавікон; `dv-avatar-640.png` – картинка для соцмереж.

## Тексти
- Мова – тільки українська.
- Тон – гострий, з авторським коментарем, але факт окремо від думки і завжди з джерелом (розділ «Голос» у BRAND.md).
- Не вигадуй новин, цифр і цитат: тільки з макета або заглушки в [квадратних дужках].
- Під кожним фото – автор і ліцензія (`design/assets/photos/CREDITS.md`).
- Тире – тільки коротке (–, U+2013), ніколи довге.

## Стек
- Статичний сайт (HTML, CSS, трохи JS), новини в `data/news.json`.
- Код у ПУБЛІЧНОМУ репозиторії GitHub (nikolfedorchenko-sys/dzerkalo-vlady, відкрито 10.10.2026 заради безлімітних хвилин GitHub Actions), викладка на Cloudflare Pages. Секрети – тільки в GitHub Secrets і autopost/.env, ніколи в коді.
- Власник проєкту не програміст: пояснюй кроки простими словами, команди давай готовими до копіювання.
- Інструкції – завжди покроково (нумеровані кроки) і з клікабельним посиланням на кожну сторінку чи налаштування (GitHub, Cloudflare тощо). Не писати «зайдіть у розділ X» без прямого посилання.
- Робота йде в хмарних сесіях Claude Code (claude.ai/code, телефон), тож після правок – коміт і push у `main`: сайт оновиться сам через Cloudflare Pages.

## Максимум автономії (вимога власника, 12.10.2026)
Claude має працювати сам, без фізичного втручання власника. Тому:
- Підключати все, що можна: конектори (GitHub, Cloudflare тощо), доступ до потрібних сайтів у мережевих налаштуваннях середовища, токени в секретах середовища чи GitHub Secrets.
- Якщо щось не відкривається чи бракує доступу (сайт, Telegram, Cloudflare, Facebook) – не обходити мовчки, а одразу дати власнику покрокову інструкцію з посиланнями, як підключити, щоб наступного разу Claude зробив це сам.
- Усе, що можна автоматизувати через GitHub Actions (розгортання Cloudflare Worker, налаштування ботів), – автоматизувати, а не просити власника робити руками.
