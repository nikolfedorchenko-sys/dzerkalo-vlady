# Сайт «Дзеркало влади» – як працювати

## Що де лежить
- `site/` – готовий сайт. Саме цю папку публікує Cloudflare Pages.
  - `index.html` – головна, `article.html` – стаття, `about.html` – «Про нас», `rubric.html` – рубрика й пошук.
  - `data/news.json` – **усі новини**. Редакція міняє тільки цей файл.
  - `css/style.css` – вигляд сайту (стиль «преміум v2»), `js/main.js` – шапка, підвал і побудова сторінок.
  - `assets/` – логотипи й фото.
- `archive/site-draft/` – попередня чернетка сайту (копія макетів), збережена про всяк випадок.

## Як подивитися сайт на своєму компʼютері
Двічі клацніть `start-site.bat` у папці проєкту – відкриється браузер із сайтом.
Просто відкрити `site/index.html` подвійним клацанням не вийде: браузер не дасть сторінці прочитати файл новин.

## Як додати новину
Відкрийте `site/data/news.json` (Блокнотом або VS Code) і скопіюйте будь-яку новину – блок від `{` до `},`. Змініть поля:

| Поле | Що писати |
| --- | --- |
| `id` | Коротка адреса латиницею через дефіс, без пробілів: `metro-dorozhchaie`. Має бути унікальною. |
| `title` | Заголовок, одна думка, до 80 знаків. |
| `cardTitle` | Необовʼязково: коротший заголовок для картки на головній. |
| `lead` | Лід – два речення: що сталося і що це означає для тебе. |
| `rubric` | Одне з: `kyivrada`, `verkhovna-rada`, `uriad`, `ofis-prezydenta`, `rozsliduvannia`, `hroshi`, `misto`, `perevirka-faktiv`, `dumka`. Порожньо `""` – без рубрики. |
| `kicker` | Необовʼязково: свій напис над заголовком замість назви рубрики («Київ · Мерія»). |
| `date` | `2026-10-09T09:55` (дата і час) або `2026-10-09` (тільки дата). |
| `author` | Автор. |
| `urgent` | `true` – новина термінова: зʼявиться червоний рядок «Терміново» вгорі всіх сторінок. Коли вже не термінова – видаліть рядок або поставте `false`. |
| `home` | `"hero"` – велика новина вгорі головної (одна); `"card"` – картка в блоці «Рішення, які зачеплять тебе» (три перші). Без поля – тільки стрічка й рубрика. |
| `photo` | `file` – шлях до фото в `site/assets/photos/`, `alt` – що на фото, `caption` – підпис, `author` і `license` – **обовʼязково**, вони друкуються під фото. |
| `impact` | Блок «Що це означає для тебе»: `text`; за потреби свій `label` («Що відомо»). |
| `body` | Текст статті – список абзаців у лапках через кому. Підзаголовок: `{ "h2": "Текст" }`. Цитата: `{ "quote": "Слова", "who": "Імʼя, посада" }`. Посилання в абзаці: `[текст](https://адреса)`. |
| `opinion` | «Думка редакції» – окремо від фактів. |
| `sources` | Джерела: `{ "title": "Рішення Київради", "url": "https://..." }`. |

Нагорі файлу: `numberOfDay` – «Цифра дня», `feedNote` – підпис під стрічкою.

Правила: кома між новинами, лапки тільки прямі `"` навколо полів, тире в тексті – коротке (–). Якщо після правки сайт показує «Не вдалося завантажити новини» – у файлі зайва чи пропущена кома. Перевірити файл можна на jsonlint.com.

Після збереження – надіслати зміни на GitHub (див. нижче), за хвилину-дві сайт оновиться сам.

## Публікація (Cloudflare Pages)
Налаштування проєкту в Cloudflare: гілка `main`, команда збірки – порожньо, папка публікації (Build output directory) – `site`.
Оновлення сайту – це просто нові зміни в репозиторії GitHub:

```
git add -A
git commit -m "Нова новина"
git push
```

## Пошуковики й прев'ю в соцмережах (серверні функції)
Сайт статичний, але три адреси Cloudflare будує на льоту з `data/news.json` – нічого генерувати руками не треба:
- `/article?id=…` – до `article.html` дописуються заголовок, опис, фото, canonical і розмітка NewsArticle саме цієї новини, а також текст статті для пошуковиків. Тому посилання у Facebook і Telegram показують фото й заголовок новини. Неіснуючий id – код 404.
- `/sitemap.xml` – карта сайту для Google (новини за 2 доби позначені для Google Новин).
- `/rss.xml` – RSS з повним текстом (для UKR.NET, Google Новин, читалок).

Код – у `functions/` (адреси) і `lib/news.js` (спільне). Ці папки лежать у корені репозиторію, а не в `site/` – так вимагає Cloudflare Pages. `site/robots.txt` вказує на карту сайту.
Перевірити локально з усіма функціями: `npx wrangler pages dev site --port 8799` (з кореня проєкту), далі відкрити http://127.0.0.1:8799/.
Якщо міняєте вигляд статті в `js/main.js` – за потреби підправте й `articleHTML` у `functions/article.js`, щоб сторінка не «стрибала» під час завантаження.
