# Сайт «Дзеркало влади»

Статичний сайт. Викладка: Cloudflare Pages, папка публікації – `site`, без команди збірки.

- `index.html` – головна (затверджений стиль «преміум v2»)
- `article.html`, `about.html` – стаття і «Про нас» (поки у стилі v1, перевести у v2 за `assets/site.css`)
- `assets/` – логотипи, фото (автори – `assets/photos/CREDITS.md`), стилі
